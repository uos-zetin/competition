# 대회 관리 (`/admin/competitions`)

대회를 만들고 관리하는 페이지. 대회 하나하나를 직접 만드는 것 외에, CSV 파일 하나로 대회+부문+참가자를 한 번에 만드는 가져오기 기능이 있다.

| 기능 | 특이사항 |
|---|---|
| 대회 생성/수정/삭제 | — |
| CSV로 가져오기 (업로드 → 대회 정보 확인 → 부문별 설정 → 처리 → 결과) | 필수 열: `이름, 소속, 로봇 이름, 참가 순번, 참가 부문, 대회 이름`. 한 CSV의 "참가 부문" 값이 같은 행끼리 자동으로 같은 부문으로 묶임 |
| 가져오기 실패 항목 재시도 | 대회/부문/참가자 단위로 성공·실패·건너뜀이 따로 표시되고, 실패한 항목만 이름을 고쳐서 재시도할 수 있음(전체를 다시 올릴 필요 없음) |
| 가져오기는 항상 **새 대회**를 만듦 | ⚠️ 기존 대회에 부문/참가자만 추가하는 용도로는 못 쓴다. 기존 부문의 참가자 중 일부만 골라 새 부문을 만들고 싶다면 [부문 관리](./admin-divisions.md)의 "기존 부문에서 선택해서 만들기"를 쓴다 |
