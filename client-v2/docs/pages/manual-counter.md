# 수동 계수 (`/counter/:counterId/manual-counter`)

라인트레이서가 계수기를 못 지나가는 등 자동 계측이 안 될 때, 사람이 스톱워치로 재서 기록을 보내는 화면. 모바일에서 빠르게 눌러야 하므로 시작/정지 버튼이 다른 화면보다 크다.

| 기능                       | 특이사항                                                                                                                                                                           |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 스톱워치(시작/정지/리셋)   | 시작을 누르면 그 시점의 현재 경연자로 고정(pin)된다 — 측정 도중 컨트롤러에서 다음 참가자로 넘어가도 이 측정은 원래 참가자 것으로 유지됨                                            |
| 기록자 이름 입력 + 전송    | 기록자 이름 없이는 전송 불가. 전송 후 스톱워치는 자동 리셋되고 이름은 유지됨                                                                                                       |
| 이번 세션에 보낸 기록 목록 | ⚠️ **이 화면을 새로고침하거나 나갔다 오면 목록이 초기화된다** — 서버 기록 자체는 남아있지만(컨트롤러의 "수동 계수 기록 취합"에서 계속 보임), 이 목록은 브라우저 세션 동안만 유지됨 |
