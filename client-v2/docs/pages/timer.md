# 타이머 (`/counter/:counterId/timer`)

경연장에 띄워두는 대형 표시 화면. 관리자가 조작하는 화면이 아니라, [컨트롤러](./controller.md)에서 진행시킨 상태를 그대로 보여주기만 하는 읽기 전용 화면이다.

| 기능 | 특이사항 |
|---|---|
| 부문/현재 경연자 이름·소속 표시 | 컨트롤러에서 참가자를 지정해야 뜬다. 이 화면 자체엔 참가자를 바꾸는 조작이 없음 |
| 카운트다운 / 스톱워치 | 부문에 제한시간이 설정돼 있으면 카운트다운, 없으면 스톱워치 — 부문 설정에 따라 자동으로 결정되고 이 화면에서 바꿀 수 없음 |
| 현재 경연자 기록 목록(상위 5개) | **승인된** 기록만 표시 — 대기/거부 상태인 기록은 안 보임 |
| 다음 경연자 목록(상위 5개) | — |
| 부문 최고 기록(상위 10명) | — |
| 스폰서 이미지 슬라이드(8초 간격, 여러 장 업로드 가능) | ⚠️ 새로 업로드하면 이전에 올렸던 이미지 전체가 교체됨(추가 아님) — 여러 장을 돌리려면 파일 선택 창에서 한 번에 다 골라야 함. ⚠️ 서버에 저장되지 않고 브라우저 메모리에만 있어서, 새로고침하거나 이 화면을 벗어나면 전부 사라짐 |
| QR 코드 | [관객용 대시보드](./dashboard.md)로 연결됨 |
