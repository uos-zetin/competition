# 계수기 선택 (`/counter`)

계수기를 하나 고르고, 그 계수기로 어떤 화면(컨트롤러/타이머/수동 계수)에 들어갈지 고르는 중간 페이지.

| 기능 | 특이사항 |
|---|---|
| 계수기 드롭다운 (연결된 부문 · 진행 상태 표시) | 목록은 새로고침 버튼을 눌러야 다시 조회됨 — 실시간 소켓이 아니라, 다른 관리자가 방금 부문에 연결해도 자동 반영되지 않음 |
| 권한별 진입 가능 화면 | **관리자**: [컨트롤러](./controller.md) · [타이머](./timer.md) · [수동 계수](./manual-counter.md) 전부 가능. **수동 기록자(manualRecorder)**: 수동 계수만 가능. **그 외**: 아무 화면도 못 감(안내 문구만 표시) |
