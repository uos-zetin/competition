# 참가자 관리 (`/admin/participants`)

대회의 부문별로 참가자를 관리하는 관리자 전용 페이지.

| 기능 | 특이사항 |
|---|---|
| 참가자 생성/수정/삭제 (대회 → 부문 단위) | — |
| 부문별 아코디언 목록 + 페이지네이션 | — |
| 참가 순번(`orderRaw`) | [컨트롤러](./controller.md)의 "부문 시작" 시 이 값 오름차순으로 참가자 호출 순서가 그대로 정해짐. 부문 내 값 중복 불가 |
| 소속/팀명(`teamName`) | [CSV 임포트](./admin-competitions.md)의 "소속" 컬럼과 같은 필드, 화면엔 "팀명"으로 표기 |
