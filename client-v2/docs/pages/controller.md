# 컨트롤러 (`/counter/:counterId/controller`)

경연 진행에 필요한 모든 조작을 하는 관리자 전용 실시간 제어판. 계수기 연결부터 기록 승인까지 한 화면에서 처리한다.

| 기능 | 특이사항 |
|---|---|
| 계수기 제어(부문 연결/해제) | 계수기 하나는 한 번에 부문 하나에만 연결 가능. 연결 해제 시 확인창 뜸 |
| 진행 상황(부문 시작/종료/초기화, 참가자 호출, 순번 미루기) | ⚠️ 부문을 "시작"해도 첫 참가자가 자동으로 지정되지 않는다 — 반드시 "첫 참가자 호출" 버튼을 눌러야 진행됨. ⚠️ "순번 미루기"는 현재 참가자를 대기열 맨 뒤로 보낼 뿐 자동으로 기록(실격 등)을 남기지 않는다 — 페널티가 필요하면 "기록 수동 추가"로 직접 넣어야 함 |
| 계수기 모니터 | 연결된 계수기의 실시간 스톱워치 상태만 보여주는 읽기 전용 |
| 타이머 제어(시작/정지, ±1초·±10초·직접 입력 조정) | 제한시간이 있는 부문에서만 뜸. 조정 버튼은 참가자가 배정된 뒤에만 활성화 |
| 수동 계수 기록 취합 | [수동 계수 페이지](./manual-counter.md)에서 여러 명이 잰 기록을 체크박스로 골라 하나로 합침. ⚠️ "평균값"이라고 표시돼도 전체 평균이 아니라 **선택한 값들의 중앙값**이다(홀수 개 선택 시 가운데 값 그대로, 짝수 개 선택 시 가운데 두 값만 평균) |
| 기록 수동 추가 | 관리자가 시간을 직접 입력해 기록으로 등록 |
| 기록 리뷰(승인/거부/메모) | 현재 참가자의 기록만 보임(전체 참가자 기록은 [기록 관리](./admin-records.md)에서) |

대부분의 패널은 **현재 참가자가 배정돼야** 활성화되고, 없으면 안내 카드로 대체된다.
