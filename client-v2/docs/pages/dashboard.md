# 대시보드 (`/dashboard`)

로그인이 필요 없는 공개 화면. 관객이 [타이머 화면](./timer.md)의 QR코드를 스캔해서 대회 진행 상황과 순위를 확인하는 용도.

| 기능 | 특이사항 |
|---|---|
| 대회/부문 선택 후 실시간 순위·진행 상황 표시 | ⚠️ 소켓 실시간이 아니라 **15초 간격 폴링**이다 — 화면이 새 기록을 반영하기까지 최대 15초 지연될 수 있음 |
| 부문 미선택 시 전체 부문 요약(부문별 미니 순위) | — |
| 부문 상태(준비/진행/종료)에 따라 다른 화면 | `ready`=시작 전 안내, `ongoing`=현재 경연자+최고 기록(완주자만), `closed`=최종 기록 |
