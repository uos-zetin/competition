# 부문 관리 (`/admin/divisions`)

대회 안의 부문(예선, 결승 등)을 만들고 관리하는 페이지.

| 기능                                       | 특이사항                                                                                                                                                                                                                                                 |
| ------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 부문 생성/수정/삭제 (이름, 설명, 제한시간) | 제한시간을 비워두면(0) [타이머 화면](./timer.md)이 카운트다운 대신 스톱워치로 뜸                                                                                                                                                                         |
| 기존 부문에서 선택해서 만들기              | 소스 부문 선택 → 참가자 선택 → 순서 지정 → 새 부문 정보 입력 순서로 진행한다. 선택된 참가자는 **복사**되고(이름/소속/로봇명 그대로, 새 참가자 레코드로 생성) 원래 부문 기록은 그대로 남는다. 순서는 기존 순서를 기본값으로 채우지만 직접 변경할 수 있다. |
