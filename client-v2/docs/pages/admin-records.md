# 기록 관리 (`/admin/records`)

대회/부문 전체를 대상으로 참가자별 기록을 모아 보고 승인·거부하는 페이지. [컨트롤러](./controller.md)의 기록 리뷰가 "현재 참가자 한 명"만 다루는 것과 달리, 여기는 대회(또는 부문) 단위로 한 번에 훑어볼 수 있다.

| 기능 | 특이사항 |
|---|---|
| 대회 → 부문 → 상태(대기/승인/거부) 필터 | 필터 상태가 URL 쿼리(`?competitionId=&divisionId=&status=`)에 저장돼, 링크를 공유하거나 새로고침해도 유지됨 |
| 참가자별 아코디언 + 기록 승인/거부/메모 | 컨트롤러와 동일한 기록 카드 UI를 재사용 |
| 상단 요약(승인/대기/거부 개수) | 현재 필터에 걸린 기록 기준으로 집계됨 |
